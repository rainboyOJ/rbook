## LCP：从开头连续匹配多长？

LCP 是 Longest Common Prefix 的缩写，意思是**最长公共前缀**。

例如，比较两个字符串：

```text
第一个：a b c d e f
第二个：a b c x y z
        └─abc─┘
```

从开头开始，前三个字符依次相同，第四个字符不同，所以它们的最长公共前缀是 `abc`，LCP 长度为 3。

LCP 要求从两个字符串的开头开始，逐个比较相邻字符。遇到不同字符，或其中一个字符串结束，匹配就停止。

### 一个字符串中，为什么会出现两个起点？

**后缀**是从某个位置开始，一直到字符串末尾的部分。

对于同一个字符串 $s$，定义：

$$
\operatorname{LCP}(i,j)=\text{从 }i\text{ 和 }j\text{ 开始的两个后缀的最长公共前缀长度}.
$$

全文使用从 0 开始的下标，字符串长度记为 $n$。

以 `ababa` 为例：

```text
下标：0 1 2 3 4
字符：a b a b a

从 0 开始的后缀：ababa
从 2 开始的后缀：aba
公共前缀：      aba
```

因此 $\operatorname{LCP}(0,2)=3$。第二个后缀先结束，不能继续匹配。

再看两个不同的起点组合：

| 起点 $(i,j)$ | 两个后缀 | LCP 长度 | 停止的原因 |
|---|---|---|---|
| $(0,2)$ | `ababa`、`aba` | 3 | 第二个后缀结束 |
| $(1,3)$ | `baba`、`ba` | 2 | 第二个后缀结束 |
| $(0,4)$ | `ababa`、`a` | 1 | 第二个后缀结束 |
| $(0,1)$ | `ababa`、`baba` | 0 | 第一个字符就不同 |

::: note

LCP 与 [[[rbook: lcs]]] 回答的问题不同。LCP 必须从两个开头开始连续匹配；最长公共子序列允许跳过字符。两个开头不相等时，LCP 直接为 0，不能跳过它们再继续寻找。

:::

## 为什么需要一次求出许多 LCP？

如果只查询一对后缀，直接逐个比较字符即可，最坏需要 $O(n)$ 时间。

但有些问题需要枚举所有起点对。共有 $O(n^2)$ 对起点，如果每一对都重新逐字符比较，最坏总时间就会达到 $O(n^3)$。例如字符串全是 `a` 时，每次匹配都可能很长。

重复工作在哪里？

比较 `ababa` 的后缀 `s[0..]` 和 `s[2..]` 时，第一对 `a` 相同。去掉这两个 `a`，接下来要做的工作，正是比较 `s[1..]` 和 `s[3..]`。

所以，不同起点对的比较过程可以共用结果。我们不必每次都把整段字符重新看一遍。

## 用二维 DP 计算 LCP

### 状态：固定两个开头

定义：

$$
lcp[i][j]=\operatorname{LCP}(i,j).
$$

两个下标分别记录两个后缀的起点。这是一个二维状态。

为了表示后缀走到末尾的情况，再约定位置 $n$ 对应空后缀：

$$
lcp[n][j]=0,\qquad lcp[i][n]=0,\qquad 0\le i,j\le n.
$$

只要其中一个后缀已经为空，公共前缀长度就是 0。

### 转移：先比较第一对字符

当 $i<n$ 且 $j<n$ 时，分两种情况：

- $s[i]\ne s[j]$：第一对字符就不同，公共前缀长度为 0。
- $s[i]=s[j]$：这一对贡献长度 1，剩余部分的长度是 $lcp[i+1][j+1]$。

于是：

$$
\boxed{
lcp[i][j]=
\begin{cases}
0, & s[i]\ne s[j],\\
1+lcp[i+1][j+1], & s[i]=s[j].
\end{cases}
}
$$

这里不需要在多个选择之间取最大值。两个起点已经固定，第一对字符能否匹配也已经确定；能够匹配，就继续比较下一对，不能匹配就停止。

为什么相等时恰好是 $1+lcp[i+1][j+1]$？去掉第一对相同字符后，任何公共前缀都变成后面两个后缀的公共前缀；反过来，给后面最长的公共前缀接回这一对字符，就得到了当前最长的公共前缀。

### 顺序：先算右下方，再算当前位置

状态依赖为：

$$
lcp[i][j]\longleftarrow lcp[i+1][j+1].
$$

放到表格里看，当前位置需要的是右下方的格子。因此可以让 $i$、$j$ 都从大到小枚举：

```cpp
for (int i = n - 1; i >= 0; i--) {
    for (int j = n - 1; j >= 0; j--) {
        if (s[i] == s[j]) {
            lcp[i][j] = lcp[i + 1][j + 1] + 1;
        } else {
            lcp[i][j] = 0;
        }
    }
}
```

代码执行前，需要准备一个至少为 $(n+1)\times(n+1)$ 的数组，并将边界第 $n$ 行、第 $n$ 列置为 0。

这里两个循环都倒序，是为了直观体现依赖关系。实际上，只要保证第 $i+1$ 行已经算完，第 $i$ 行里的 $j$ 也可以正序枚举，因为转移没有依赖本行的其他格子。

### 手算 ababa

先沿着依赖链看 $lcp[0][2]$：

```text
lcp[0][2]：a == a，需要 1 + lcp[1][3]
lcp[1][3]：b == b，需要 1 + lcp[2][4]
lcp[2][4]：a == a，需要 1 + lcp[3][5]
lcp[3][5]：第二个后缀为空，值为 0
```

实际填表时，顺序反过来：

$$
\begin{aligned}
lcp[3][5]&=0,\\
lcp[2][4]&=1+0=1,\\
lcp[1][3]&=1+1=2,\\
lcp[0][2]&=1+2=3.
\end{aligned}
$$

完整表格如下，最后一行和最后一列是空后缀边界：

| $i\backslash j$ | 0：a | 1：b | 2：a | 3：b | 4：a | 5：空 |
|---|---|---|---|---|---|---|
| 0：a | 5 | 0 | **3** | 0 | 1 | 0 |
| 1：b | 0 | 4 | 0 | **2** | 0 | 0 |
| 2：a | 3 | 0 | 3 | 0 | **1** | 0 |
| 3：b | 0 | 2 | 0 | 2 | 0 | **0** |
| 4：a | 1 | 0 | 1 | 0 | 1 | 0 |
| 5：空 | 0 | 0 | 0 | 0 | 0 | 0 |

表格还有两个可以自查的性质：$lcp[i][j]=lcp[j][i]$，并且 $lcp[i][i]=n-i$。

共有 $O(n^2)$ 个状态，每个状态只比较一对字符、读取一个已知状态，所以时间为 $O(n^2)$，保存整张表的空间为 $O(n^2)$。

## 应用：ABC141 E 的不重叠重复子串

题目链接：[[[p: atcoder-abc141_e | Who Says a Pun?]]]

给定字符串，求一个最长的非空字符串，使它在原串中至少出现两次，而且选出的两次出现不能重叠。不存在时，答案为 0。

注意答案是**重复部分本身的长度**。例如 `abcabc` 的答案是 3，对应两次 `abc`。

### 先固定两个起点

设两次出现的起点为 $i,j$，且 $i<j$，共同长度为 $len$。

第一条限制是两个子串相等。它们必须在从 $i,j$ 开始的公共前缀内，因此：

$$
len\le lcp[i][j].
$$

第二条限制是不能重叠。第一个子串占据 $[i,i+len-1]$，第二个从 $j$ 开始，因此：

$$
i+len-1<j\quad\Longleftrightarrow\quad len\le j-i.
$$

将两个上界合在一起，固定这对起点时的最大合法长度就是：

$$
\boxed{len=\min\bigl(lcp[i][j],j-i\bigr).}
$$

这个值不仅是上界，也一定可以取到：它没有超过公共前缀长度，所以两段相等；它没有超过起点距离，所以两段不重叠。值为 0 时，表示这对起点无法提供非空答案。

最后枚举全部起点对：

$$
\boxed{
ans=\max_{0\le i<j<n}\min\bigl(lcp[i][j],j-i\bigr).
}
$$

### 为什么 ababa 的答案不是 3？

对于 $i=0,j=2$，有 $lcp[0][2]=3$，但两个长度为 3 的 `aba` 占据的区间分别是 $[0,2]$ 和 $[2,4]$，共用了位置 2。

把长度限制为 2，则两个 `ab` 占据 $[0,1]$ 和 $[2,3]$，不再重叠。

| 起点 $(i,j)$ | LCP 长度 | 起点距离 $j-i$ | 最大合法长度 |
|---|---|---|---|
| $(0,2)$ | 3 | 2 | 2 |
| $(1,3)$ | 2 | 2 | 2 |
| $(0,4)$ | 1 | 4 | 1 |
| $(0,1)$ | 0 | 1 | 0 |

LCP 负责限制“能够相等多长”，起点距离负责限制“多长才不会重叠”。两个限制都必须保留。

## 和连续段 DP 有什么关系？

前一篇 [[[rbook: continuous_segment_dp]]] 讲过：固定距离 $d$，比较 $s[i]$ 与 $s[i+d]$，再统计连续匹配的字符对。

ABC141 E 也能这样做。这里没有问号，两个字符必须直接相等。

### 固定距离，就是沿着 LCP 表的一条对角线

固定 $d=j-i$ 后，比较的字符对依次为：

$$
(s[0],s[d]),\ (s[1],s[1+d]),\ (s[2],s[2+d]),\ \ldots
$$

这些位置对在二维表中，恰好位于同一条从左上到右下的对角线上。

以 `ababa`、$d=2$ 为例，三对字符都相等：

| 左侧位置 $i$ | 0 | 1 | 2 |
|---|---|---|---|
| 比较的字符对 | `(a, a)` | `(b, b)` | `(a, a)` |
| 从左到右算：以当前位置结尾的连续匹配对数 | 1 | 2 | 3 |
| 从右到左算：$lcp[i][i+2]$ | 3 | 2 | 1 |

它们描述的是同一段匹配关系，但状态的端点不同：

- 连续计数固定的是**结尾**，所以依赖前一对，扫描时向前累加。
- LCP 固定的是**开头**，所以依赖后一对，填表时从后向前累加。

不要把同一位置的 `cnt` 和 `lcp[i][i+d]` 当成同一个值。例如表中 $i=0$ 时，前者为 1，后者为 3。

### 连续匹配对数如何变成不重叠答案？

设扫描到左侧位置 $i$ 时，连续匹配对数为 `cnt`。若从这段末尾取出 $k$ 对，则两段相同子串占据：

$$
[i-k+1,i],\qquad [i+d-k+1,i+d].
$$

它们不重叠，要求第一段的结尾在第二段的起点之前，即：

$$
i<i+d-k+1\quad\Longleftrightarrow\quad k\le d.
$$

同时，能够取出的字符对数不能超过 `cnt`，所以当前可以提供的最大合法长度为：

$$
\boxed{\min(cnt,d).}
$$

枚举所有距离，并扫描该距离下的全部位置，就覆盖了所有可能的子串对。对于任意一对长度为 $k$ 的合法相同子串，设其起点为 $l,l+d$；扫描到 $i=l+k-1$ 时，连续匹配对数至少为 $k$，且不重叠保证 $k\le d$，因此不会漏掉它。


注意这里的 $d$ 要枚举到 $n-1$。两次出现可以相隔很远，中间允许有空隙。例如 `abcxabc` 的两次 `abc` 相距 4，虽然答案长度只有 3，仍然需要检查 $d=4$。

| 比较项目 | 二维 LCP DP | 固定距离 + 连续计数 |
|---|---|---|
| 如何组织字符对 | 按两个起点填二维表 | 按起点距离逐条扫描对角线 |
| 状态含义 | 从两个起点开始的连续匹配长度 | 截至当前位置的连续匹配对数 |
| 依赖方向 | 右下方的下一个位置对 | 左上方的前一个位置对 |
| 不重叠限制 | $\min(lcp[i][j],j-i)$ | $\min(cnt,d)$ |
| 时间 | $O(n^2)$ | $O(n^2)$ |
| 额外空间 | $O(n^2)$ | $O(1)$ |

二维 LCP 表可以保留任意起点对的查询结果；固定距离计数在本题中只需维护全局答案，因此不必保存整张表。

### 与 CF1948D 的条件有什么区别？

两道题都可以固定距离、统计连续匹配，但对匹配段的要求不同。

| 条件 | CF1948D | ABC141 E |
|---|---|---|
| 字符匹配 | 相等，或至少一个是问号 | 必须相等 |
| 两段的位置关系 | 两半必须相邻 | 两次出现不能重叠，允许有空隙 |
| 固定距离 $d$ 后 | 需要连续至少 $d$ 对，组成两个长度为 $d$ 的半段 | 可以取不超过 $d$ 的连续匹配对 |
| 对答案的贡献 | 整个重复串长度 $2d$ | 单次出现的长度 $\min(cnt,d)$ |

因此，CF1948D 中“达到 $d$ 就返回 $2d$”的代码不能直接搬到本题。应该先检查两题中“相邻”“不重叠”以及“答案长度”的具体含义。

## 三个自查练习

### 练习一：LCP 很长，合法长度也一定很长吗？

设 `s = "aaaaaa"`，分别计算起点对 $(0,1)$ 和 $(0,3)$ 的 LCP 长度与最大不重叠长度。本题的全局答案是多少？

::: fold

对于 $(0,1)$，LCP 为 5，起点距离为 1，合法长度为 $\min(5,1)=1$。

对于 $(0,3)$，LCP 为 3，起点距离为 3，合法长度为 $\min(3,3)=3$。

全局答案为 3，对应两次 `aaa`。任意两段长度为 $k$ 的不重叠子串总共占据 $2k$ 个位置，所以 $2k\le 6$，不可能超过 3。

:::

### 练习二：为什么遇到不相等的字符必须归零？

设 `s = "xabzab"`。虽然两个起点后面都出现了 `ab`，为什么 $lcp[0][3]=0$？

::: fold

从位置 0 和 3 开始的后缀分别是 `xabzab`、`zab`。第一对字符 `x` 与 `z` 不同，因此公共前缀为空，LCP 长度为 0。

后面的 `ab` 可以由另一对起点查询：$lcp[1][4]=2$。不能跳过当前不同字符，把后面的相同部分算成当前后缀的公共前缀。

:::

### 练习三：只看当前匹配段的总长度够吗？

在 `ababa` 中固定 $d=2$，连续匹配了 3 对字符。为什么只能贡献长度为 2 的答案，而不能贡献 3？

::: fold

长度为 3 的两段是位置 $[0,2]$ 的 `aba` 和位置 $[2,4]$ 的 `aba`，它们重叠。距离只有 2，要避免重叠，所取长度也必须不超过 2。

因此使用 $\min(cnt,d)=\min(3,2)=2$。

:::
