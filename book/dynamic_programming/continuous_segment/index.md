本篇在顺序固定的数组、字符串上，按原下标扫描并维护结尾状态。按权值插入元素、维护连通块数量的另一类模型，见 [[[rbook: component_dp]]]。

## 连续正数段

给定一个数组，求最长的连续正数段。例如：

```text
下标 i：  0   1   2   3   4   5   6
元素 a：  2   5  -1   3   4   6   0
```

答案是 3，对应连续的三个正数 `[3, 4, 6]`。

**连续段**要求元素在原数组中相邻，不能跳过中间元素。全文下标从 0 开始。本节不存在非空连续正数段时，答案记为 0。

枚举起点并向右扩展，遇到非正数停止。所有元素均为正数时，不同起点会重复扫描同一位置，总时间为 $O(n^2)$。

这些检查可以复用。例如扫描到 `6` 时，已知它前面紧邻两个连续正数 `3, 4`，便可得到长度 3，无须重新检查前面的元素。

因此，扫描到位置 $i$ 时，只需知道**紧邻其左侧的连续正数段长度**，再判断当前元素能否延长这一段。

## 结尾状态

### 状态定义

定义：

$$
dp[i]=\text{必须以位置 }i\text{ 结尾的最长连续正数段长度}
$$

如果 $a[i]\le 0$，就不存在以它结尾的非空连续正数段，令 $dp[i]=0$。

“必须以 $i$ 结尾”保证上一状态的非空段紧邻 $a[i]$，可以尝试接上当前元素。例如扫描到 `6` 时，能够延长的是 `[3, 4]`，而非更早的 `[2, 5]`。

### 转移方程

只有两种情况：

- $a[i]>0$：延长前一段，长度加 1；前一段为空时，从当前位置开始。
- $a[i]\le 0$：不存在以当前位置结尾的合法非空段，长度为 0。

于是得到：

$$
dp[i]=
\begin{cases}
dp[i-1]+1, & a[i]>0,\\
0, & a[i]\le 0.
\end{cases}
$$

约定 $dp[-1]=0$，仅用于统一公式，代码不能访问数组的 `dp[-1]`。

当 $a[i]>0$ 时，前一段接上当前元素，得到长度 $dp[i-1]+1$。反之，任意以 $i$ 结尾的合法段，去掉末项后，剩余部分为空或是以 $i-1$ 结尾的合法段，长度不超过 $dp[i-1]$。因此该转移恰好得到最长长度。

### 手算示例

| 位置 $i$ | $a[i]$ | 当前发生了什么 | $dp[i]$ | 扫描至此的最长长度 |
|---|---|---|---|---|
| 0 | 2 | 正数，开始新的一段 | 1 | 1 |
| 1 | 5 | 接在位置 0 后面 | 2 | 2 |
| 2 | -1 | 当前段被打断 | 0 | 2 |
| 3 | 3 | 重新开始一段 | 1 | 2 |
| 4 | 4 | 接在位置 3 后面 | 2 | 2 |
| 5 | 6 | 接在位置 4 后面 | 3 | 3 |
| 6 | 0 | 当前段被打断 | 0 | 3 |

**当前段长度**与**扫描至此的最长长度**不同。当前元素非正时，前者归零，后者不变。

### 代码实现

假设数组 `a` 长度为 `n`，`dp` 已分配至少 `n` 个位置：

```cpp
int ans = 0;
for (int i = 0; i < n; i++) {
    if (a[i] > 0) {
        dp[i] = 1;
        if (i > 0) {
            dp[i] += dp[i - 1];
        }
    } else {
        dp[i] = 0;
    }
    ans = max(ans, dp[i]);
}
```

时间复杂度为 $O(n)$，保存 `dp` 数组的额外空间为 $O(n)$。

## 前缀最优值

也可以定义前缀中的最优值：

$$
f[i]=\text{前 }i\text{ 个位置中，最长的连续正数段长度}
$$

“前 $i$ 个位置”指下标 $0$ 到 $i-1$，$f[0]=0$。这个状态记录了答案，却没有保留末尾连续段的信息。

把正数记为 1、非正数记为 0，比较两个前缀：

```text
前缀 A：1 1 0
前缀 B：0 1 1
```

两者都有 $f[3]=2$。现在都在末尾接上一个 1：

```text
A：1 1 0 1    最长连续 1 的长度仍然是 2
B：0 1 1 1    最长连续 1 的长度变成了 3
```

前缀最优值和新元素相同，结果却不同。因此，**只知道 $f[3]$ 和新元素，无法确定下一步的答案**。缺少的是末尾连续段长度：A 为 0，B 为 2。

先用 $dp[i]$ 记录可延续的段，再更新前缀最优值：

$$
f[i+1]=\max\bigl(f[i],dp[i]\bigr),\qquad f[0]=0.
$$

| 状态 | 含义 | 是否保留末尾段信息 |
|---|---|---|
| $dp[i]$ | 必须以 $i$ 结尾的最长长度 | 是 |
| $f[i]$ | 前 $i$ 个位置中的最长长度 | 否 |

状态既要能表示答案，也要保留推导后续状态所需的信息。

## 最大连续子段和

给定长度为 $n\ge1$ 的整数数组，求一个**非空连续子段**，使元素和最大。元素可以为负数。

例如 `[4, -1, 2, -7, 3]` 的答案为 $5$，对应 `[4, -1, 2]`。负数不一定使最优段结束：中间的 $-1$ 仍可与两侧元素共同组成更优子段，不能照搬“遇到非正数归零”的规则。

### 状态定义

本节将状态值由长度改为元素和：

$$
dp[i]=\text{非空且必须以位置 }i\text{ 结尾的最大子段和}.
$$

固定结尾，才能保证前一段与当前元素相邻。全局答案为：

$$
ans=\max_{0\le i<n}dp[i].
$$

答案可以在任意位置结束，不能只取 $dp[n-1]$。

### 转移方程

以 $i$ 结尾的非空段只有两类：

- 只包含 $a[i]$，和为 $a[i]$。
- 长度至少为 2，去掉末项后是以 $i-1$ 结尾的非空段。其最大和为 $dp[i-1]$，接上当前元素后为 $dp[i-1]+a[i]$。

因此：

$$
dp[0]=a[0],\qquad
dp[i]=\max\bigl(a[i],dp[i-1]+a[i]\bigr),\quad 1\le i<n.
$$

两类覆盖全部合法段，且各自的最优值都能取到。对第二类，不同前段接上相同的 $a[i]$，大小关系不变，因此只保留前一结尾的最大和即可。

这就是 **Kadane 算法**。转移也可写成 $dp[i]=a[i]+\max(0,dp[i-1])$：前段和为负时舍弃前段，否则延长；为 0 时两者等价。这里比较的是**前段和**，不是当前元素的正负。

### 手算示例

| $i$ | $a[i]$ | 处理方式 | $dp[i]$ | 扫描至此的最大和 |
|---|---|---|---|---|
| 0 | 4 | 初始单元素段 | 4 | 4 |
| 1 | -1 | 延长前段 | 3 | 4 |
| 2 | 2 | 延长前段 | 5 | 5 |
| 3 | -7 | 延长前段，仍优于单独取 -7 | -2 | 5 |
| 4 | 3 | 前段和为负，从当前位置重开 | 3 | 5 |

扫描到 $-7$ 时，结尾状态变成 $-2$，已得到的全局答案仍为 $5$。下一项到来时，才根据这个负的前段和决定重开。

### 代码实现

只需保存上一结尾的最大和。假设 `a` 是 `vector<long long>`，长度为 `n >= 1`，且子段和在 `long long` 范围内：

```cpp
long long cur = a[0];
long long ans = a[0];
for (int i = 1; i < n; i++) {
    cur = max(a[i], cur + a[i]);
    ans = max(ans, cur);
}
cout << ans << '\n';
```

处理完位置 $i$ 后，`cur` 等于 $dp[i]$，`ans` 是此前所有结尾状态的最大值。时间复杂度为 $O(n)$，除输入数组外的额外空间为 $O(1)$。

### 空段与边界

上述状态和代码要求子段非空。全负数组 `[-5, -2, -7]` 的答案为 $-2$，所以 `ans` 不能初始化为 $0$。

若题目允许空段，空段和为 $0$，只需将非空答案再与 $0$ 取最大值：$\max(0,ans)$。不必改变 $dp[i]$ 的非空含义。

| 数组 | 非空答案 | 允许空段的答案 |
|---|---|---|
| `[-5, -2, -7]` | -2 | 0 |
| `[0]` | 0 | 0 |
| `[3]` | 3 | 3 |
| `[4, -1, 2, -7, 3]` | 5 | 5 |

在此基础上，若还要记录某次操作是否开始或结束，就需要为同一结尾区分更多状态，见 [[[rbook: dp_state_machine]]]。

## 其他连续段

### 相同字符段

例如字符串 `aabbbaa`，最长连续相同字符段是 `bbb`，长度为 3。

定义 $dp[i]$ 为以 $i$ 结尾的最长连续相同字符段长度。当前字符与前一个相同时，可以延长：

$$
dp[i]=
\begin{cases}
dp[i-1]+1, & i>0\text{ 且 }s[i]=s[i-1],\\
1, & \text{其他情况}.
\end{cases}
$$

不能延长时，长度为 1，因为单个字符也是合法段。

| 位置 $i$ | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| 字符 | a | a | b | b | b | a | a |
| $dp[i]$ | 1 | 2 | 1 | 2 | 3 | 1 | 2 |

核心转移为：

```cpp
for (int i = 0; i < n; i++) {
    dp[i] = 1;
    if (i > 0 && s[i] == s[i - 1]) {
        dp[i] = dp[i - 1] + 1;
    }
}
```

### 严格递增段

例如数组 `[2, 4, 3, 5, 7, 1]`，最长严格递增连续段是 `[3, 5, 7]`，长度为 3。

定义 $dp[i]$ 为以 $i$ 结尾的最长严格递增连续段长度。当 $a[i]>a[i-1]$ 时，当前元素可以接上前一段：

$$
dp[i]=
\begin{cases}
dp[i-1]+1, & i>0\text{ 且 }a[i]>a[i-1],\\
1, & \text{其他情况}.
\end{cases}
$$

| 位置 $i$ | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| $a[i]$ | 2 | 4 | 3 | 5 | 7 | 1 |
| $dp[i]$ | 1 | 2 | 1 | 2 | 3 | 1 |

核心转移为：

```cpp
for (int i = 0; i < n; i++) {
    dp[i] = 1;
    if (i > 0 && a[i] > a[i - 1]) {
        dp[i] = dp[i - 1] + 1;
    }
}
```

这里要求连续。[[[rbook: lis]]] 允许跳过元素，不能直接套用相邻位置转移。

### 边界对照

| 问题 | 能够延续的条件 | 不能延续时的状态 |
|---|---|---|
| 连续正数段 | 当前元素为正数 | 0，当前元素不能组成合法段 |
| 连续相同字符段 | 当前字符与前一个相同 | 1，当前字符单独成段 |
| 严格递增连续段 | 当前元素大于前一个 | 1，当前元素单独成段 |

不能延长时取 0 还是 1，取决于**当前元素能否单独构成合法段**。

## CF1948D：重复子串

题目链接：[[[p: codeforces-1948D | Tandem Repeats]]]

给定由小写字母和 `?` 组成的字符串。每个 `?` 可独立替换为任意小写字母，求最长的重复子串：它由两个相邻且相同的字符串拼接而成。不存在时输出 0。

例如 `aabaab` 的前半段和后半段都是 `aab`，因此它是一个长度为 6 的合法重复串。

需要比较前后两半的对应位置，不能直接比较相邻字符。

### 固定半长

设一半的长度为 $d$。如果整个重复串从 $l$ 开始，需要比较的字符对恰好是：

$$
(s[l],s[l+d]),\ (s[l+1],s[l+d+1]),\ \ldots,\ (s[l+d-1],s[l+2d-1]).
$$

两字符能够匹配，当且仅当它们相等，或者至少有一个是 `?`。

固定 $d$ 后，定义匹配序列：

$$
b[i]=
\begin{cases}
1, & s[i]=s[i+d]\text{，或二者中至少一个是问号},\\
0, & \text{其他情况},
\end{cases}
\qquad 0\le i<n-d.
$$

那么，从 $l$ 开始的长度为 $2d$ 的子串合法，恰好等价于：

$$
b[l]=b[l+1]=\cdots=b[l+d-1]=1.
$$

因此，只需判断匹配序列中是否存在**连续至少 $d$ 个 1**。

选定的两个半段中，每个位置只属于一对，因此这 $d$ 对可以独立完成替换，不会发生问号取值冲突。即使匹配段更长，也只需选中的 $d$ 对同时成立。

### 连续匹配

固定 $d$，定义：

$$
dp[i]=\text{在匹配序列中，以位置 }i\text{ 结尾的最长连续 1 的长度}.
$$

这与连续正数段的状态形式相同：

$$
dp[i]=
\begin{cases}
dp[i-1]+1, & b[i]=1,\\
0, & b[i]=0,
\end{cases}
\qquad dp[-1]=0.
$$

这里 $dp[i]$ 是**连续匹配的字符对数**。当 $dp[i]\ge d$ 时，取最后 $d$ 对，即得到长度为 $2d$ 的重复串。

### 手算示例

以没有问号的字符串为例：

```text
下标 i：0 1 2 3 4 5 6 7
字符 s：z a a b a a b z
```

固定 $d=3$：

| 位置 $i$ | 比较的字符 | $b[i]$ | $dp[i]$ |
|---|---|---|---|
| 0 | `s[0]=z` 与 `s[3]=b` | 0 | 0 |
| 1 | `s[1]=a` 与 `s[4]=a` | 1 | 1 |
| 2 | `s[2]=a` 与 `s[5]=a` | 1 | 2 |
| 3 | `s[3]=b` 与 `s[6]=b` | 1 | 3 |
| 4 | `s[4]=a` 与 `s[7]=z` | 0 | 0 |

到 $i=3$ 时，已经连续匹配了 $d=3$ 对：

$$
(s[1],s[4]),\ (s[2],s[5]),\ (s[3],s[6]).
$$

它们对应前半段 `s[1..3] = aab` 和后半段 `s[4..6] = aab`，得到长度为 6 的重复串。

一般地，在位置 $i$ 达到连续 $d$ 对时，左半段起点为 $l=i-d+1$，重复串范围为 $s[l..i+d]$。循环条件 $i+d<n$ 保证右端不越界。

### 枚举半长

固定 $d$ 只能判断长度为 $2d$ 的重复串是否存在，还需枚举 $1\le d\le\lfloor n/2\rfloor$。

从大到小枚举 $d$，首次找到合法重复串即可返回，因为更大的长度均已检查。

枚举 $d$ 和起点，再逐对检查，最坏需要 $O(n^3)$ 时间。使用连续段 DP 后，每个 $d$ 只扫描一次，总时间为 $O(n^2)$。

## 空间优化

计算 $dp[i]$ 只依赖 $dp[i-1]$，可以用变量 `cnt` 保存当前连续段长度。以连续正数段为例：

```cpp
int cnt = 0;
int ans = 0;
for (int i = 0; i < n; i++) {
    if (a[i] > 0) {
        cnt++;
    } else {
        cnt = 0;
    }
    ans = max(ans, cnt);
}
```

处理完位置 $i$ 后，`cnt` 等于 $dp[i]$，`ans` 等于 $f[i+1]$。状态含义不变，时间仍为 $O(n)$，额外空间降为 $O(1)$。

这是滚动变量优化，与本书“状态压缩”章节讨论的二进制状态表示不同。

CF1948D 也无须保存匹配数组 `b`，扫描时直接比较字符。下面的函数返回最长重复子串的长度，假设已引入 C++ 标准库并使用 `std` 命名空间：

```cpp
int longest_tandem(const string &s) {
    int n = s.size();
    for (int d = n / 2; d >= 1; d--) {
        int cnt = 0;  // 每次更换距离，都重新开始计算连续匹配对数
        for (int i = 0; i + d < n; i++) {
            if (s[i] == s[i + d] || s[i] == '?' || s[i + d] == '?') {
                cnt++;
            } else {
                cnt = 0;
            }
            if (cnt >= d) {
                return 2 * d;
            }
        }
    }
    return 0;
}
```

对长度为 $n$ 的一个字符串，总时间为 $O(n^2)$，除输入字符串外的额外空间为 $O(1)$。

## 适用条件

设计连续段状态时，需要检查：

1. 合法段能否由前一段接上当前元素得到。
2. 上一状态和相邻元素是否足以判断延续。
3. 不能延续时，当前元素能否单独成段。
4. 答案要求某个结尾、全局最优，还是达到指定长度。

这些条件用于指导状态设计，转移仍需证明。

例如，“区间内最多出现两个不同的数”也要求连续，但只记录末尾合法段长度通常不够。加入新元素后，还需要区间内的数及其出现次数，才能调整左边界。因此，“以当前位置结尾”并不意味着转移一定是“加一或归零”。

相同字符段和严格递增段的较短后缀都合法，延续时保留最长段即可。其他区间条件是否也具有这个性质，需要另行检查。

## 思考练习

### 练习一：非递减段

求最长的连续非递减段，也就是允许相邻元素相等。

写出 $dp[i]$ 的含义、延续条件，以及不能延续时的取值。

::: fold 参考分析

状态为“以 $i$ 结尾的最长连续非递减段长度”。当 $i>0$ 且 $a[i]\ge a[i-1]$ 时，令 $dp[i]=dp[i-1]+1$；其他情况为 1，因为单个元素也是非递减段。

:::

### 练习二：两种状态

对于序列 `[1, 1, 0, 1]`，把每个 1 看作合法元素、0 看作不合法元素，分别写出 $dp[0..3]$ 和 $f[0..4]$。

::: fold 参考分析

$$
dp=[1,2,0,1],\qquad f=[0,1,2,2,2].
$$

末项的结尾状态为 1。此前的最优段虽长为 2，但与末项之间隔着 0，无法延续。

:::

### 练习三：连续匹配

CF1948D 中，固定 $d=2$，设字符串为 `a?ab`。写出匹配序列，判断能否得到长度为 4 的重复串，并给出一种问号替换方式。

::: fold 参考分析

比较的两对是 `(a, a)` 和 `(?, b)`，都可以匹配，所以 $b=[1,1]$、$dp=[1,2]$。连续匹配对数达到 $d=2$，将问号替换为 `b` 后得到 `abab`。

单对匹配只说明对应字符兼容；构成长度为 $2d$ 的重复串，需要连续 $d$ 对均可匹配。

:::

### 练习四：负数与重开

对数组 `[2, -1, 2, -5, 4]`，写出最大连续子段和的 $dp[0..4]$。为何扫描到 $-1$ 时延长前段，而最后一项需要重开？

::: fold 参考分析

$$
dp=[2,1,3,-2,4].
$$

前三项的最优段 `[2, -1, 2]` 含负数 $-1$，说明不能遇负即断。到位置 3 时，结尾和变为 $-2$，所以最后一项单独成段更优。全局答案为 $4$，对应 `[4]`。

:::

### 转化与组合

| 题目 | 训练目标 |
|---|---|
| [[[p: codeforces-327A | CF327A：Flipping Game]]] | 将翻转一个 $0$ 的收益记为 $+1$、翻转一个 $1$ 的收益记为 $-1$，转为最大子段和。必须恰好翻转一个非空区间，全为 1 时答案是 $n-1$，不能取空段规避操作。 |
| [[[p: codeforces-1948D | CF1948D：Tandem Repeats?]]] | 本文例题。固定半长 $d$，把字符对转为匹配序列，检查是否连续匹配至少 $d$ 对；答案长度为 $2d$。 |
| [[[p: luogu-P2642 | P2642：最大双子段和]]] | 用前缀、后缀最优值组合两个非空子段。两段之间必须至少间隔一个元素，不能只保证互不相交。 |

CF327A 的最终答案是原有 1 的数量加上最大翻转收益；最大收益可能为负。P2642 的两段均非空，即使数组全负，也必须选出两段。

### 状态机衔接

学完 [[[rbook: dp_state_machine]]] 后，再做 [[[p: codeforces-1155D | CF1155D：Beautiful Array]]]：至多选一个区间乘以 $x$，求操作后的最大子段和，答案允许为空。需要同时保留结尾位置和“操作前、操作中、操作后”三种阶段，不能仅靠一个结尾最优值完成转移。
