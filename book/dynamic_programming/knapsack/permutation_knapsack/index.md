## 问题引入

在 [[[rbook: knapsack_variants]]] 中，求「装满容量 $C$ 的方案总数」时，普通背包统计的是**组合数**——选哪些物品，不区分放入顺序。

当题目要求区分顺序（统计**排列数**）时，必须把顺序纳入状态或转移。按物品数量是否受限，处理方式分成两类：

- **无限件物品（完全背包）**：直接交换两层循环顺序即可。
- **有限件物品（01 / 多重背包）**：换循环顺序不再成立，需要改用**插入背包**，把状态定义成已排好的序列长度。

## 完全背包中的排列计数

先看每种物品有无限件的情形，对应题目 [[[p: luogu-U663733 | 疯狂的背包问题(7) - 完全背包问题（计数排列问题）]]]。

::: definition 问题模型
有 $N$ 种物品和一个容量为 $V$ 的背包，每种物品有无限件，第 $i$ 种物品体积为 $v_i$。求恰好装满体积 $V$ 的**不同放入顺序**总数（对 $10^9+7$ 取模）。
:::

### 循环顺序的差异

回顾完全背包求方案数的两种循环写法：

| 循环顺序 | 转移含义 | 统计结果 |
| --- | --- | --- |
| 外层物品 $i$，内层容量 $j$ | 强制物品按编号从小到大依次加入 | 组合数 |
| 外层容量 $j$，内层物品 $i$ | 对体积 $j$ 枚举**最后一个**放入的物品 | 排列数 |

外层物品、内层容量时，第 $1$ 种物品的选取总在第 $2$ 种之前确定，因此 `{1, 2}` 只会被计入一次，`1-2` 与 `2-1` 不会分别统计。

==外层容量、内层物品时，每个非空排列都可以按「最后放入哪一种物品」唯一划分==。因为每种物品无限供应，只要 $j \ge v_i$，任意总体积为 $j - v_i$ 的合法排列末尾都能追加一件第 $i$ 种物品，且不会与第 $i$ 种物品在前面出现过多少次发生冲突。

### 状态定义与转移方程

设 $f[j]$ 表示总体积恰好为 $j$ 的合法放入顺序数。初始条件 $f[0] = 1$（空序列有 $1$ 种），其余为 $0$。转移方程为：

$$
f[j] = \sum_{i=1}^{N} [\,j \ge v_i\,]\, f[j - v_i]
$$

计算时按 $j = 1 \sim V$ 从小到大递推，对每组 $(j, i)$ 累加并对 $10^9 + 7$ 取模。时间复杂度 $O(NV)$，空间复杂度 $O(V)$。

## 有限件物品为什么不能只换循环

如果把物品限制改成「每件最多选 $1$ 次」或「第 $i$ 类最多选 $cnt_i$ 次」，交换循环顺序会立即出错：

1. **无法防重**：只记录当前容量（或长度）$j$ 时，状态 $f[j - v_i]$ 里不知道第 $i$ 类物品已经用过几次，继续追加第 $i$ 类物品可能超出数量上限。
2. **不能直接乘阶乘**：若所有物品互不相同，选出 $m$ 件的排列数等于组合数乘 $m!$；一旦存在**相同元素**（例如 `{a, a, b}` 取 $2$ 个），不同组合对应的重复度不同（`aa` 有 $1$ 种排列，`ab` 有 $2$ 种排列），不能在组合数外面统一乘 $m!$。

因此，有限件物品求排列必须把**每一类物品的选取过程逐类合并**，并把「序列长度」本身作为背包容量。

## 插入背包

### 状态定义与转移方程

设有 $n$ 类物品，第 $i$ 类有 $cnt_i$ 个相同副本，目标排列长度为 $m$。

设 $dp[j]$ 表示**仅使用前几类物品，已经排成长度为 $j$ 的序列方案数**。初始 $dp[0] = 1$，其余为 $0$。

处理第 $i$ 类物品时，假设从该类中取 $c$ 个（$0 \le c \le \min(cnt_i, j)$）放入序列，使总长度从 $j - c$ 变成 $j$。在长度为 $j$ 的目标序列中，挑出 $c$ 个位置放置这 $c$ 个**相同**物品，其余 $j - c$ 个位置按原顺序保留已排好的元素，选位方案数为 $\binom{j}{c}$。

由此得到转移方程（$ndp$ 为当前轮的新数组）：

$$
ndp[j] = \sum_{c=0}^{\min(cnt_i, j)} dp[j - c]\binom{j}{c}
$$

==背包容量在这里是「已排列长度」，转移时乘 $\binom{j}{c}$ 统计插入位置数，从而直接维护排列数而非组合数==。最终答案为 $dp[m]$。

::: note 两个特例
1. **互异元素（01 情形，$cnt_i = 1$）**：$c$ 只能取 $0$ 或 $1$，方程退化为 $ndp[j] = dp[j] + j \cdot dp[j - 1]$，即把新元素插入长度为 $j$ 序列的 $j$ 个位置之一，最终 $dp[m] = P(n, m)$。
2. **有重复元素**：例如 `{a, a, b}`（$cnt = [2, 1]$）取长度 $m = 2$。处理 `a` 后得 $dp = [1, 1, 1]$（空、`a`、`aa`）；再处理 `b` 时，$dp'[2] = dp[2]\binom{2}{0} + dp[1]\binom{2}{1} = 1\times 1 + 1\times 2 = 3$，恰好对应 `aa`、`ab`、`ba`。
:::

### 组合数计算与变体扩展

::: warn 组合数取模的写法选择
若模数为大于 $m$ 的质数（如 $10^9 + 7$），可预处理阶乘与逆元 $O(1)$ 计算 $\binom{j}{c}$；若模数不是质数或小于等于 $m$，应使用杨辉三角 $O(m^2)$ 预处理组合数，避免逆元不存在。
:::

如果题目在限制件数的同时，还要求总体积恰好为 $V$，只需像 [[[rbook: two_dim_cost]]] 那样把总体积加进第二维：

- 状态改为 $dp[j][v]$：已排成长度为 $j$、总体积为 $v$ 的方案数；
- 选 $c$ 个第 $i$ 类物品（单件体积为 $w_i$）时，转移自 $dp[j - c][v - c \cdot w_i] \cdot \binom{j}{c}$。

::: fold 指数型生成函数（EGF）视角
第 $i$ 类物品至多选 $cnt_i$ 个时，其在指数型生成函数中的因子为：

$$
F_i(x) = \sum_{c=0}^{cnt_i} \frac{x^c}{c!}
$$

全部物品组合成长度为 $m$ 的排列数为：

$$
m!\,[x^m]\prod_{i=1}^{n} \left(\sum_{c=0}^{cnt_i} \frac{x^c}{c!}\right)
$$

若把状态定义为 $\widetilde{dp}[j] = \frac{dp[j]}{j!}$，插入背包的转移就变成 $\widetilde{ndp}[j] = \sum_{c} \widetilde{dp}[j-c]\cdot \frac{1}{c!}$，即逐个乘上多项式 $F_i(x)$ 的卷积过程；最后乘回 $m!$ 即为答案。
:::

## 适用边界与小结

| 场景 | 做法 |
| --- | --- |
| 物品无限，按体积求排列 | 一维完全背包，外层枚举容量、内层枚举物品 |
| 物品有限（01 / 多重），求长度排列 | 插入背包，状态记已排长度，转移乘 $\binom{j}{c}$ |
| 物品有限，同时限制长度与体积 | 二维插入背包 $dp[j][v]$ |

插入背包只记录序列长度和各物品使用量，不记录具体位置和末尾元素。如果题目额外要求**相邻元素不能相同**、**环形排列**或**某些物品必须相邻**，仅有长度状态不够，需要改用状压 DP、记录末尾信息的插入 DP 或容斥处理。
