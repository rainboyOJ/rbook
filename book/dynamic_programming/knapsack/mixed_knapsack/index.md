::: definition 混合背包
有 $n$ 件物品和一个容量为 $C$ 的背包。第 $i$ 件物品给出重量 $w_i$、价值 $v_i$，以及一个标记 $p_i$：
$p_i=1$ 表示只能用一次，$p_i=0$ 表示能用无限次，$p_i>1$ 表示最多用 $p_i$ 次。求最大价值。
:::

## 关键：循环方向

回看 01 背包和完全背包的一维写法，两者只差一个地方：

```cpp
// 01 背包：容量倒序
for (int j = C; j >= w; --j) f[j] = max(f[j], f[j-w] + v);

// 完全背包：容量正序
for (int j = w; j <= C; ++j) f[j] = max(f[j], f[j-w] + v);
```

为什么方向能决定「用几次」？

- **倒序**时，算 $f[j]$ 用到的 $f[j-w]$ 还是**上一轮**（没考虑当前物品）的值，所以当前物品最多被放一次；
- **正序**时，$f[j-w]$ 已经是**本轮**更新过的值，也就是「已经放过当前物品」的结果，于是可以接着再放，形成无限次。

所以混合背包根本不需要新的状态设计——**按物品种类选择循环方向**即可。

## 抽象出三个过程

如果三种背包各自写成一个函数，混合背包的主循环会非常干净：

```cpp
for (int i = 1; i <= n; ++i) {
    if (p[i] == 1)      ZeroOnePack(f, w[i], v[i]);
    else if (p[i] == 0) CompletePack(f, w[i], v[i]);
    else                MultiplePack(f, w[i], v[i], p[i]);
}
```

这正是《背包问题九讲》强调的一点：**把每种背包处理成「一件物品的过程」**，之后无论怎么组合都不会乱。

## 小结

混合背包是「抽象」带来的收益最直观的一讲：只要三种基本背包各自封装好，混合起来不过是加几个 `if`。

真正需要记住的只有一件事——**倒序 = 只用一次，正序 = 可用无限次**。后面遇到任何「循环方向」的疑惑，回到这句话就能想清楚。
