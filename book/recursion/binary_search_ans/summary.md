::: definition 1 二分性（单调谓词分割）

设搜索空间为全序集合 $X$，给定判定谓词 $check(x) \in \{0, 1\}$。如果序列在 $check$ 的映射下呈现分段单调的特性，则称该问题具备**二分性**。

最常见的两种形态如下：

1. **形态一（先 0 后 1，求第一个可行解 / 最小值模型）**：
   $$
   \color{blue}{\underbrace{0, 0, \cdots, 0}_{check = 0}},\quad
   \color{red}{\underbrace{1, 1, \cdots, 1}_{check = 1}}
   $$
   特征：越大越容易满足要求，求满足要求的**最小位置**。

2. **形态二（先 1 后 0，求最后一个可行解 / 最大值模型，即二分答案）**：
   $$
   \color{red}{\underbrace{1, 1, \cdots, 1}_{check = 1}},\quad
   \color{blue}{\underbrace{0, 0, \cdots, 0}_{check = 0}}
   $$
   特征：越小越容易满足要求，求满足要求的**最大位置**。

:::

::: theorem 1 闭区间随手记账二分法则

在闭区间 $[l, r]$ 上统一使用 `while (l <= r)`，维护记账变量 `ans`。根据最优化目标，仅需对称调整合法时的试探方向：

#### 模型 A：找满足条件的最小值（最左端点）
```cpp
int ans = -1; // 初始为无解哨兵
while (l <= r) {
    int mid = (l + r) / 2;
    if (check(mid)) {
        ans = mid;    // 合法，立即记账！
        r = mid - 1;  // 贪心向左缩小，寻找更小解
    } else {
        l = mid + 1;  // 不合法，向右收缩
    }
}
```

#### 模型 B：找满足条件的最大值（最右端点，二分答案）
```cpp
int ans = -1; // 初始为无解哨兵
while (l <= r) {
    int mid = (l + r) / 2;
    if (check(mid)) {
        ans = mid;    // 合法，立即记账！
        l = mid + 1;  // 贪心向右冲刺，寻找更大解
    } else {
        r = mid - 1;  // 不合法，向左收缩
    }
}
```

:::

::: tip 记账法相比传统分界二分的 3 大优势
1. **彻底告别死循环**：循环体内永远对称地使用 `l = mid + 1` 与 `r = mid - 1`，闭区间长度严格减小，数学上保证在 $\lfloor \log_2(r - l + 1) \rfloor + 1$ 步内必然退出；
2. **零差一边界心智负担**：搜索空间就是真实的业务区间 $[l, r]$，无需在末尾制造 $\infty$ 哨兵，也无需在求最大值时反向“减 1”；
3. **现场打包方案参数**：在 `check(mid)` 成功时，若检验过程产出了伴随方案（如合法区间的起始坐标、分割方案），可直接在 `if (check(mid))` 块内就地存下，避免二分结束后再度线性扫描。
:::
