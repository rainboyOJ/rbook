## 定义: 整除

一般的，设 $a, b$ 为整数，且 $b \neq 0$。如果存在整数 $q$，使得：
$$a = b \cdot q$$
那么称 $b$ **整除** $a$，或者说 $a$ 能被 $b$ 整除，记作：
$$b \mid a$$
并且称 $b$ 是 $a$ 的因数（约数），$a$ 是 $b$ 的倍数。如果这样的整数 $q$ 不存在，就称 $b$ **不整除** $a$，记作 $b \nmid a$。

## 理解除法：用刀砍木条

我们发现在 C++ 代码中 `10 / 5 = 2`（念作：十除以五），`11 / 5 = 2`。怎样才能更好地从直观上理解整除与带余除法呢？

先从“除”字的本意来看：
> ①〈名词〉台阶。《史记·魏公子列传》：“赵王扫除自迎，执主人之礼，引公子就西阶。”  
> ②〈动词〉清除，去掉。《荆轲刺秦王》：“而燕国见陵之耻除矣。”《出师表》：“攘除奸凶，兴复汉室。”

“除法”的“除”在这里作为动词：**去除、砍断、分割**。
- 式子 $10 \div 5 = 2$：用“以”（以表示“用”），意思就是**用长度为 5 的刀去砍长度为 10 的木条**，恰好可以完整砍出 2 根长度为 5 的小木条，没有碎片残留；
- 被除数是 10（被砍的物体），除数是 5（主动拿来当尺子砍的工具）。

当无法整除时（例如 $11 \div 5$），砍出两根长为 5 的木条后，还剩下一个长度为 1 的小木头碎片，这个碎木头就是**余数**：
$$11 = 2 \times 5 + 1$$

## 整除的核心性质

初等数论中，整除具有以下几个最基本的公理级性质：

1. **自反性**：对任意非零整数 $a$，恒有 $a \mid a$；
2. **传递性**：若 $a \mid b$ 且 $b \mid c$，则必有 $a \mid c$。  
   *证明：由条件存在整数 $k_1, k_2$ 使得 $b = a k_1, c = b k_2$，代入得 $c = a (k_1 k_2)$，因 $k_1 k_2$ 亦为整数，故 $a \mid c$。*
3. **线性组合保持性**：若 $a \mid b$ 且 $a \mid c$，则对于任意整数 $x, y$，恒有 $a \mid (bx + cy)$。

## 核心推论：传递性的逆否命题（一票否决法则）

在算法竞赛与数学证明中，整除传递性最锋利的用法往往不是它的正向形式，而是它的**逆否命题**：

::: theorem 推论（传递性的逆否命题 / 一票否决性）
已知正整数 $a, b$ 满足 $a \mid b$（即 $a$ 是 $b$ 的因数）。  
若某个待检验的数 $S$ 满足 $a \nmid S$（连较小的因数 $a$ 都无法整除），则必然有：
$$b \nmid S$$
即大数 $b$ 也绝对无法整除 $S$。
:::

### 1. 反证法严格证明

我们在形式逻辑中知道：原命题成立，则其逆否命题必然等价成立。

反证如下：
1. 假设结论不成立，即假设大数 $b$ 能够整除 $S$（$b \mid S$）；
2. 又已知前提 $a \mid b$（大数 $b$ 本身是小数 $a$ 的倍数）；
3. 由整除的传递性，由 $a \mid b$ 与 $b \mid S$ 必然能推导出：
   $$a \mid S$$
4. 这与我们已知的前提条件 $a \nmid S$ 发生了**不可调和的矛盾**！
5. 因此反设不成立，必然有 $b \nmid S$。

### 2. 直观生活比方：大面额钞票与硬币

你可以把整除看作找零钱：
- 设 $a = 2$ 元钞票，$b = 24$ 元大钞（显然 $2 \mid 24$）；
- 现在的目标是检验某个金额 $S$ 能否被 24 元大钞整除。

如果我们在清点时发现：金额 $S$ 是一个奇数（例如 $S$ 包含了一个孤立的 1 元硬币，导致 $2 \nmid S$），请问你还需要去拿 24 做除法吗？
**完全不需要！** 因为 24 元大钞本身全是由 2 元凑成的（$2 \mid 24$），它无论乘以几张，总面额都必然是偶数。一个数连 2 元都除不尽，它就**绝无可能**被 24 元整除！

### 3. 算法竞赛中的实战价值

在竞赛中，当目标模数 $b$ 是一个极其庞大的数（如 $b = x!$ 或 $b = 2^{60}$），直接计算 $S \bmod b$ 往往面临高精度溢出或无法处理的困境。

此时的破局策略通常是：
1. 找到大数 $b$ 的一个关键低阶因子 $a$（满足 $a \mid b$）；
2. 检验 $S$ 能否被较小的因数 $a$ 整除；
3. **一旦发现 $a \nmid S$，立刻利用一票否决法则宣判 $b \nmid S$ 并提前退出**（典型例题：CF 1753B Factorial Divisibility）。

## 总结

在 C++ 代码中：
```cpp
int a = 11, b = 5;
int q = a / b; // 商：能完整砍出多少段
int r = a % b; // 余数：砍完后剩下的碎片
```
- 整除对应 `r == 0`，不整除对应 `r != 0`；
- 牢记整除传递性的逆否命题：**连因子都除不尽，大数更不可能除得尽**。
