## 字符串算法处理什么

字符串算法研究字符序列中的匹配、前缀、后缀、回文与循环结构。本章从逐字符比较出发，再讨论如何复用已经匹配的信息，避免重复工作。

## 学习路线

| 主题 | 核心问题 |
| --- | --- |
| [[[rbook: string-brute-force]]] | 枚举每个起点，逐字符验证一个模式串 |
| [[[rbook: string-hash]]] | 预处理前缀指纹，快速比较子串 |
| [[[rbook: manacher]]] | 利用回文对称性，求所有中心的回文半径 |
| [[[rbook: kmp]]] | 失配后保留最长可用前后缀，在线性时间内完成单模式匹配 |
| [[[rbook: trie]]] | 共享多个字符串的公共前缀，支持集合查询与前缀计数 |
| [[[rbook: ac-automaton]]] | 结合 Trie 和失配指针，同时匹配多个模式串 |
| [[[rbook: minimal-string]]] | 在线性时间内选出字典序最小的循环移位 |
| [[[rbook: string-boyer-moore]]] | 从模式串末尾比较，利用失配信息跳过候选起点（当前仅迁移参考索引） |

先掌握字符串下标、前缀与后缀，再学习朴素匹配与字符串哈希。回文问题用 Manacher 处理对称性；单模式匹配在朴素做法的基础上学习 KMP。多个字符串的共同前缀可以用 [[[rbook: trie]]] 组织；多模式匹配则在此基础上继续学习 AC 自动机。
