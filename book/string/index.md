## 字符串算法处理什么

字符串算法研究字符序列中的匹配、前缀、后缀、回文与循环结构。本章从逐字符比较出发，再讨论如何复用已经匹配的信息，避免重复工作。

## 学习路线

| 主题 | 核心问题 |
| --- | --- |
| 朴素匹配 | 枚举每个起点，逐字符验证一个模式串 |
| KMP | 失配后保留最长可用前后缀，在线性时间内完成单模式匹配 |
| Trie 字典树 | 共享多个字符串的公共前缀，支持集合查询与前缀计数 |
| AC 自动机 | 结合 Trie 和失配指针，同时匹配多个模式串 |
| 字符串哈希 | 预处理前缀指纹，快速比较子串 |
| Manacher | 利用回文对称性，求所有中心的回文半径 |
| 最小表示法 | 在线性时间内选出字典序最小的循环移位 |
| Boyer–Moore | 从模式串末尾比较，利用失配信息跳过候选起点 |

先掌握字符串下标、前缀与后缀，再学习朴素匹配和 KMP。多个字符串的共同前缀可以用 [[[rbook: trie]]] 组织；多模式匹配则在此基础上继续学习 AC 自动机。
