## 判断回文串

### 一句话

回文串的定义就是**首尾成对相等**，所以判定它最自然的写法不是"造一个反串来比"，而是**两根指针从两端向中间夹**：一步比一对，相等就同时收一格，不等立刻退出。

### 先看最直接的写法

```cpp
string t = s;
reverse(t.begin(), t.end());
bool ok = (s == t);
```

这写法没错，但要多开一份 $O(n)$ 的空间，而且**必须先把整串反过来才有结论**。

双指针写法的空间是 $O(1)$，更重要的是它手里有一个"落点"：一旦 `s[i] != s[j]`，我们立刻知道**是哪一对字符对不上**。本书后面所有回文相关的题——最少改几个字符、能不能补字符、从中心往外扩、Manacher——都是在这个落点上做文章。这就是判断回文串必须用双指针的真正理由。

循环条件写 `i < j` 而不是 `i <= j`：长度是奇数时中间那个字符自己和自己比，一定相等，没必要看它。

### 例题：[[[p: luogu-P17828 | [CSP-J 2026] 回文串]]]

#### 题意

长度为 $L$ 的字符串 $S$ 不直接给出，而是压缩成 $n$ 段：第 $i$ 段是 $a_i$ 个字符 $c_i$，依次拼接就是 $S$。相邻两段可以同色。每次可以把任意一个位置的字符改成任意小写字母，问**最少改几个位置**能让 $S$ 变成回文串。

- $1 \le n \le 2\times 10^5$，$1 \le a_i \le 10^9$
- 于是 $L = \sum a_i$ 最大到 $2\times 10^{14}$，**串本身是造不出来的**

#### 第一步：把"最少修改"翻译成"数出多少对不等"

对每个 $i < L+1-i$，把 $(s_i, s_{L+1-i})$ 叫做**一对镜像位置**。

::: oneWordAlgo

最少修改次数 = 字符不相等的镜像位置的**对数**。

:::

**证明**（下界）：若某一对镜像位置字符不同，最终它们必须相同，而一次修改只动**一个**位置，所以这一对至少贡献一次修改。

**证明**（上界）：对每一对不相等的镜像位置，只改左边（或只改右边）那一个字符，把它改成另一边即可。不同镜像位置集合互不相交（一个位置只属于一对），所以这样一共正好改"对数"次。

两条夹起来，答案就是不相等的对数。长度是奇数时，最中间那个位置没有镜像搭档，它爱是什么是什么，不产生任何代价。

::: warning

这一步很容易写成"统计有多少个字符和它的镜像不相同"，那样答案会翻倍。要数的是**对**，不是字符。

:::

#### 第二步：不能展开，就让指针走"段"

既然答案只跟"某一对镜像位置的字符是否相同"有关，我们仍然用双指针的思想：左指针在最左端、右指针在最右端，一对一对往中间收。

区别只在于：**指针走的不是字符，而是段**。段 $i$ 还剩 `remL` 个字符没被配对，段 $j$ 还剩 `remR` 个，那么这一轮能一次配掉

$$
k = \min(\text{remL}, \text{remR})
$$

对。这 $k$ 对的左半边全是 `c[i]`、右半边全是 `c[j]`：

- `c[i] == c[j]`：这 $k$ 对全部相等，一次贡献 $0$；
- `c[i] != c[j]`：这 $k$ 对全部不等，一次贡献 $k$。

配完就把两边的剩余量各减 $k$，谁先减到 $0$ 谁的段指针就往里挪一格，并把新段的全长装进剩余量。

#### 复杂度

- 时间：$O(n)$。每一轮至少有一个段指针前进一格，而指针只走 $n$ 格。
- 空间：$O(n)$，只存段。
- 注意 $L$ 只能当**数值**用（算剩余量、累加答案），绝不能当数组下标。答案最大约 $10^{14}$，`int` 装不下，`ans` 要 `long long`。

#### 容易踩的坑

- 段指针挪到 `li == ri` 时就该停：中间剩下的那段是**自己和自己配对**，字符必然相同，贡献恒为 0。
- 相邻同色的段（比如 `a a a`）不用合并，代码照样对；只是合并之后循环轮数更少。别为了合并把 $a_i$ 累加到 `int` 溢出。
- 只有一段时（$n=1$）答案直接是 0，循环一次都不进。

### 例题：[[[p: luogu-P10905 | [蓝桥杯 2024 省 C] 回文字符串]]]

#### 题意

给定只含小写字母的串 $S$，可以在 $S$ 的**开头**加入任意多个只由 `l`、`q`、`b` 组成的字符，问能否把 $S$ 变成回文串。多组数据，$1 \le T \le 10$，$1 \le \sum |S| \le 10^6$。

#### 把"补字符"翻译成两条约束

设补上的串为 $P$，长度 $m$，目标是 $P+S$ 是回文串。先说明 $m$ 只需要考虑 $0 \le m \le n$：当 $m > n$ 时，$S$ 的每个字符的对称位置都落在 $P$ 里，条件退化成"$S$ 全是 `l/q/b`"，而这种情况取 $m = n$ 也能做到。所以下面只讨论 $m \le n$。

看 $P+S$ 里位置 $t$（从 0 数）的对称位置 $m+n-1-t$：

- $t \ge m$：两边都落在 $S$ 里，这一层要求 $S[t-m] = S[n-1-t]$。把所有这样的 $t$ 写开，就是一句话——**$S$ 的长度为 $n-m$ 的前缀必须是回文串**（这部分只能用双指针去验，补字符帮不上忙）。
- $t < m$：左边是补的字符，右边落在 $S$ 里，要求 $P[t] = S[n-1-t]$。而 $P[t]$ 可以随便取，只要属于 `{l,q,b}`，所以这一层唯一的限制是——**$S$ 的长度为 $m$ 的后缀必须全是 `l`、`q`、`b`**。

把 $x = n-m$ 代进去，结论是：

::: oneWordAlgo

答案是 Yes ⟺ 存在 $x \in [0,n]$，使 $S$ 的**前 $x$ 个字符本身回文**，且**后 $n-x$ 个字符全部属于 `{l,q,b}`**。

:::

### 同源，但不该塞进这一章

- [[[p: luogu-P10902 | [蓝桥杯 2024 省 C] 回文数组]]]（普及−）：同样是"配对"，但一次操作能同时动相邻两个数，代价可以在相邻对之间**共享/传递**。样例 `1 2 3 4` 答案是 3，而不是把两对的差分别相加得到的 4，就说明了这点。外层仍用双指针配对，代价怎么算要自己推。
- [[[p: luogu-P16960 | [SCCPC 2026] 那一天的回文字符串]]]（普及−）：奇/偶下标上的字符可以各自重排，问能否变回文。本质是"配对能不能凑齐"的计数/匹配，双指针只是外层框架。
- [[[p: luogu-P1015 | [NOIP 1999 普及组] 回文数]]]（普及−）：主题是模拟 + 高精度，但**判定回文这一步**正好用本模板（位数不多，双指针 $O(\text{位数})$）。
- [[[p: luogu-P1206 | [USACO1.2] 回文平方数]]]、[[[p: luogu-P2010 | [NOIP 2016 普及组] 回文日期]]]（普及−）：主题是枚举候选，回文判定同样是本模板的子过程。
- [[[p: luogu-P1435 | [IOI 2000] 回文字串]]]（普及+/提高−）：**不是双指针**。最少插入次数 = $n$ 减最长回文子序列，而最长回文子序列就是 $S$ 与 $\text{reverse}(S)$ 的 LCS，属区间 DP / LCS，见 [[[rbook: lcs]]]。
- [[[p: luogu-P3649 | [APIO2014] 回文串]]]、[[[p: luogu-P6216 | 回文匹配]]]、[[[p: luogu-P1872 | 回文串计数]]]（省选及以上）：回文**算法**题，正解是 Manacher / 回文自动机 / 哈希，双指针只能拿到最暴力的分数。

### 这一节的易错点

- **`i < j` 还是 `i <= j`**：判整串回文用 `i < j`；如果题目要求"每对都要相等"且长度可能为奇数，中心那一位要单独想清楚，别顺手多比一次。
- **下标从 0 还是从 1 开始**：模板里两种都给了（`string` 版从 0、数组版从 1），混用时最容易错的是 `j = size()-1` 与 `j = n` 的区别。
- **答案的类型**：涉及长度累加的题（比如 P17828）答案能到 $10^{14}$，`int` 会静默溢出。
- **不要构造长串**：压缩输入、$L$ 达 $10^{14}$ 的题，一律让指针走"段"或走"下标区间"，不要 `string` 拼接。
- **字符集**：`'a'` 与 `'A'` 是不同字符；判回文前是否统一大小写、是否忽略非字母，要按题意来，别想当然。
