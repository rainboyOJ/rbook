# 文章关系画布

页面路径为 `/brain_net_map/`，使用本地打包的 G6，不依赖 CDN。先在项目根目录运行 `npm run prepare`，再进入本目录运行 `bash build.sh`，产物写入 `dist/brain_net_map/`。开发时在本目录运行 `npx vite`。

## 视图与数据含义

| 名称 | G6 布局 | 数据 |
| --- | --- | --- |
| 知识网络（默认） | ForceAtlas2 | 作者声明的前置关系 |
| 学习路线 | AntV Dagre | 作者声明的前置关系；断开的连通分量单独打包排列 |
| 章节分组 | ComboCombined，章内、章间网格 | 作者声明的前置关系，按顶层章节分组 |
| 中心辐射 | Radial | 作者声明的前置关系，选中文章优先作为中心 |
| 章节脑图 | Mindmap | 书籍 → 章节 → 子目录 → 文章 |
| 展开阅读 | Indented，参考 Fund Flow 的卡片与分支展开交互 | 目录层级 |

关系视图的箭头始终为前置文章 → 后续文章；目录视图没有箭头，不把目录归属冒充知识依赖。没有连线的文章也保留在画布上。章节过滤展示本章全部文章和直接跨章邻居，不递归向外扩展。

目录视图的全书入口先折叠各章；双击目录或使用详情中的按钮展开、折叠。搜索文章会展开它的祖先目录。切换到具体章节时展开目录。

## 交互

- 拖动背景平移，拖动节点改变位置；鼠标位置滚轮缩放，手机双指缩放。
- 单击选中并展示可关闭的浮动详情，不重新布局或改变镜头；双击文章进入阅读。
- 搜索包含标题、菜单短名、文章 ID 和章节名，支持上下方向键、Enter 和 Escape。
- 切换布局保留选中文章。布局计算有迭代上限，结束后统一播放位置过渡，随后保持静止。
- 学习路线等卡片视图首次进入保留可读比例；“适应”按钮可查看全图。圆点视图的标签在缩小时保持阅读字号，并由 G6 自动避让。
- 画布聚焦后，方向键平移，`+` / `-` 缩放，`0` 适应画布，Escape 关闭详情。遵守系统减少动画设置。

## 实现与验证

- `load_data.js` 使用发布管线的目录和元数据解析器，注入可见文章、完整目录层级及声明的 `pre` 关系。未知前置引用警告并跳过。
- `model.mjs` 管理章节邻域、目录投影、折叠、辐射中心和连通分量打包；不依赖浏览器。
- `app.js` 管理 G6 生命周期和交互，异步操作串行执行，避免快速切换时并发修改画布。开发服务器提供`window.__knowledgeMap()` 调试句柄用于浏览器检查，发布版本不暴露此句柄。
- `style.css` 管理全屏浅色画布、浮动控件及手机底部详情。

项目根目录运行 `node --test tests/article-relations.test.js` 验证过滤、目录树、折叠搜索和分量打包规则。浏览器验收需覆盖六种视图往返切换、无边章节、跨章搜索、真实拖拽、双击阅读、手机双指缩放和减少动画设置。
