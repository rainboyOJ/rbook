# Rbook 学术正文样式

状态：已定稿并实施。用户确认于 2026-10-28，取代第一轮的无衬线正文方案。

## 目标与范围

以 DFS 序文章为首个验收样本，采用中文学术书籍和 LaTeX 中文论文的字体分工与留白方式，使读者扫视时能辨认章节、性质、解释和图表。适用于全站文章正文，侧边栏、导航和工具按钮沿用站点壳样式。

## 定稿参数

| 元素 | 参数与呈现 |
| --- | --- |
| 文章标题 | 系统黑体 `36px / 48px`、700，居中 |
| 大节 H2 | 系统黑体 `28px / 40px`、700，上间距 56px、下间距 16px |
| 小节与性质 H3 | 系统黑体 `22px / 34px`、700，上间距 36px、下间距 12px |
| H4 | `20px / 30px`、700，上间距 28px、下间距 8px |
| H5 / H6 | `18px / 30px`、700，上间距 24px、下间距 8px |
| 普通正文 | 自托管 Noto Serif SC 宋体，`18px / 30px`，首行缩进 2em，段间距 8px |
| 正文版心 | 最大 684px，约 38 个汉字，居中；桌面内边距 24px，手机 16px |
| 段内强调 | 系统黑体 600，继承正文字号 |
| 页内目录 | 系统黑体 `16px / 26px`，使用与正文一致的显示编号 |
| 图片 | 居中、等比缩放，上下间距 24px，保留图中含义色 |
| 图注 | `14px / 22px`，与图片间距 8px；不自动把长篇 alt 转成图注 |
| 表格 | `16px / 26px`，三线表，宽表内部横向滚动 |
| 块公式 | KaTeX 字体，上下间距 20px，超宽公式内部滚动 |
| 代码块 | 系统等宽 `14px / 22px`，保留行号、复制按钮和内部滚动 |
| 提示框 | 淡语义底色、2px 左边线、明确的“说明／注意／错误”标签 |
| 一句话算法 | 普通正文字号，轻量底色与细边线 |
| 折叠答案 | 克制的展开入口，保留键盘焦点及展开操作 |

字体、字号和留白共同区分层次，标题不加装饰横线。文章开头与连续标题减少多余间距，标题靠近其下方正文。首行缩进只作用于普通叙述段落；列表、引用、图注、表格、代码、提示框、独立图片与独立公式不缩进。

## 编号与目录

普通章节使用 `1`、`1.1` 等多级编号。`P1`、`P2`、`性质 1`、`一、`、`2.1` 等作者已有的明确编号独立显示，不叠加自动编号；`2-SAT`、`P2P` 等术语仍视为标题文字。自动编号按标题所在位置递增，作者编号不改变其他章节的位置计数。

Markdown 渲染器先按原文建立锚点，再生成正文与目录共享的显示编号。保留文章路径、现有锚点、标题级别和 P1～P6 引用。长标题换行后与标题文字对齐；页内目录覆盖 H2、H3，与既有目录深度一致。

## 字体资源与维护

采用 **@fontsource/noto-serif-sc 5.3.1** 的常规 400 字重，保留上游完整字符范围的 101 个 WOFF2 分包，总计 3,182,532 字节。资源在 `src/public/fonts/noto-serif-sc/`，随网站发布；读者无需连接第三方字体服务。

`400.css` 根据 Unicode 范围按需加载，使用 `font-display: swap`，不预加载全部中文字形包。加载前或失败时回退到系统宋体，再回退到浏览器衬线字体；超出上游字符集的字符由系统字体补足。分包不局限于 DFS 序文章已有汉字，后续文章无需重新裁字。

来源、OFL-1.1 授权、包版本、tarball 校验和及每个分包的 SHA-256 随资源保存。[更新脚本](../scripts/vendor-noto-serif.py) 可从固定来源重建资产，日常构建无需联网下载字体。标题、强调、代码和 KaTeX 各自保留对应字体角色。

## 明暗主题与手机

两种主题共用几何参数，分别使用匹配背景的文字、边框与提示框颜色。图例保留原始配色，不进行通用反色处理。

手机正文仍为 `18px / 30px`；文章标题降至 `30px / 42px`，H2 降至 `26px / 38px`，性质标题保持 22px。宽表、代码与公式局部滚动。手机标题跳转预留顶部工具按钮的空间。

## 实现位置

- `src/style/article-shell.scss`：字体、字号、版心和间距变量。
- `src/markdown-style/typography.scss`：局限于文章区域的排版规则。
- `src/publishing/markdown/plugins/toc.ts`：共享标题编号与目录，保留原有锚点。
- `src/publishing/markdown/plugins/containers.ts`：可读的提示框标签。
- `src/markdown-style/vendor/markdown-r.scss`、`markdownPlugin/oneWordAlgo.scss`：提示框与一句话算法样式。
- `src/ejs/article.html`：本地字体样式表入口。
- `tests/fixtures/markdown/typography.md`：标题、正文、宽表、公式、图注、代码和容器的综合验证样例。

## 验收要求

1. 真实 DFS 序文章在桌面与 375px 手机上，明暗主题均层次清晰，普通段落缩进正确，无整页横向溢出。
2. P1～P6 不叠加章节号，目录编号与标题一致，现有锚点仍可访问。
3. 五组答案可展开，焦点可见，代码可以复制，图例不丢失。
4. 首访字体按需请求，复访可缓存，字体失败时正文仍可读。
5. 综合 fixture 和其他典型文章检查通过，核心发布构建包含所有字体资产。

### 本次验收记录

2026-10-28，在本机 Chromium 检查构建后的 DFS 序、前缀和及综合 fixture：桌面 1366px、手机 375px，浅色与暗色共 12 种组合均通过。正文行宽与字号符合定稿，整页无横向溢出，图片完整，目录编号与锚点一致；折叠答案可展开且键盘焦点可见，实际点击复制后的剪贴板内容与代码一致。

DFS 序首访加载 19 个字体分包，文件内容合计 759,032 字节；本机复访测试命中缓存，字体传输为 0。浏览器实际使用自托管字体；阻断字体请求后使用系统宋体，正文仍可读；罕见汉字可混用上游分包与系统字形。缓存结果取决于发布服务器的缓存配置，本次数据来自本地静态服务。

根目录 170 项测试、全项目类型检查通过，核心构建成功发布 128 篇文章。新增回归覆盖作者编号、重复标题锚点、目录转义、字体分包完整性和可见提示框标签。
