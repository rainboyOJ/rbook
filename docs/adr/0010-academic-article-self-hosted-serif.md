# 学术正文采用自托管宋体与共享标题编号

为改善算法长文扫读时的层次，正文改用自托管 Noto Serif SC，标题与强调使用系统黑体，正文基线为 18px/30px、最大版心 684px。用户接受字体资产与下载成本，选择跨设备较一致的宋体效果；采用完整 Unicode 分包、按需加载及 `font-display: swap`，保留系统字体回退，不依赖第三方字体服务。此决定替代 ADR 0009 的无衬线正文、16px/24px、42em 和仅用系统字体约束；文章局部作用域、系统等宽代码、KaTeX 和站点壳边界继续保留。

标题显示编号在 Markdown 渲染阶段生成，目录复用该编号，原文锚点先行生成并保留。作者已有性质编号独立显示，避免 CSS 计数器与目录各自编号造成重复或不一致。

## Consequences

- 提交约 3.18 MB 的 WOFF2 资产、OFL 许可及固定版本清单；升级时运行带校验的更新脚本并重新检查换行与字符覆盖。
- 首次阅读会请求文章所需的分包；字体替换可能改变换行，失败时使用系统宋体或衬线字体。
- 全站文章统一应用，必须持续检查目录锚点、宽表、公式、代码、提示框与手机阅读，不能只验收单篇文章。

参数与实现见 [学术正文样式定稿](../article-academic-typography.md)。
