# 左侧菜单与搜索

首页和文章页共用 `src/component/sidebar-search.ejs`、`site-shell.js` 与文章壳样式。搜索直接索引菜单中的文章标题和祖先目录名称，包含尚未展开的文章，不检索正文，不发起网络请求。

关键词以空白分隔，忽略英文大小写，全部匹配后才展示。标题精确匹配、前缀匹配优先，其余结果保留目录顺序。结果显示标题与分类路径，匹配文字使用文本节点构建高亮。

搜索框固定在菜单顶部。输入后下方切换为结果列表，显示匹配数；中文输入法选字期间不触发跳转。向下键进入结果，上下键切换结果，Enter 打开，Escape 或清空按钮恢复原目录。

状态分别保存：

- `localStorage` 的 `rbook.sidebar.expanded.v1`：目录展开状态。
- `sessionStorage` 的 `rbook.sidebar.scroll.v1`：当前标签页的原目录滚动位置。
- `sessionStorage` 的 `rbook.sidebar.search.v1`：当前标签页的关键词和搜索结果滚动位置。

搜索期间不覆盖原目录滚动位置；从结果打开文章后继续显示搜索，清空时还原原目录及其位置。恢复搜索的页面不额外展开当前文章的父目录，避免改变搜索前的目录状态。页面离开前同步保存，兼容快速点击导航。无 JavaScript 时隐藏搜索框，保留普通菜单；浏览器禁用存储时仍可在当前页面搜索。

回归检查包括多关键词、目录路径、大小写、排序、空查询与非法存储，以及 `tests/sidebar-scroll.test.js` 中的滚动恢复用例。浏览器检查应覆盖连续打开结果后清空、结果列表滚动恢复、中文输入、键盘、手机菜单和深浅主题。
