## 为什么需要状态机 DP？从 Kadane 谈起

在学习动态规划时，我们最先接触的线性模型往往是**一维连续段 DP**（如最大连续子段和 / Kadane 算法）：

> 设 $dp[i]$ 表示以位置 $i$ 结尾的最大子段和。  
> 转移方程为：$dp[i] = \max(a[i], \ dp[i-1] + a[i])$。

这个模型之所以只需要一维，是因为它的规则在整条数组上是**完全对称、一视同仁的**——无论扫到哪一个位置，决策都只有简单的两选一：“继续接在前面”还是“另起炉灶”。

然而，真实的算法竞赛和工程面试中，出题人往往会加入某种**“附加规则”**或**“特权配额”**：
- *“相邻的两个元素不能同时选择”*；
- *“你允许挑选至多一个连续子区间，将其中的所有数值乘上 $x$”*；
- *“每次交易后必须强制冷却一天，才能进行下一次交易”*。

一旦出现这种限制，普通的一维 $dp[i]$ 就崩溃了：因为扫描到位置 $i$ 时，光知道“以 $i$ 结尾的值是多少”已经不够用了，我们还必须知道：**当前的特权用过了没有？当前正处于什么操作身份？**

很多同学在面对这类题目时，容易有两个误区：
1. **盲目贪心**：比如试图先求一次最小子段乘上 $x$，再去求最大子段（后面会证明这必错）；
2. **状态维度膨胀**：误以为要像背包问题那样，开一个很大的维度记录花费。

其实，这种附加规则的底层本质是：**我们在随线性序列前进的同时，自身在一个“微型的有限状态机（Finite State Machine, FSM）”里流转**。第二维根本不需要记录庞大的数字，它只需要记录我们当前处于哪一个**有限的离散状态代码（$0, 1, 2$）**！

下面我们通过循序渐进的“三级台阶”，彻底掌握这一思维模型。

## 第一台阶：互斥二态选择（选 / 不选）

最基本的状态机，是在每个位置拥有两种相互制约的身份。

### 经典模型：打家劫舍（House Robber）

> 给定一个非负整数数组，每个数代表一间房屋里的现金。相邻的房屋装有防盗报警，**不能同时偷取相邻的两间房**。求能偷到的最高金额。

如果只定义 $dp[i]$ 为前 $i$ 间的最大收益，由于第 $i$ 间“偷与不偷”会直接决定第 $i+1$ 间能不能偷，无后效性被破坏。

#### 状态机建模

在每一间房屋前，小偷只可能处于两种状态之一：
- **状态 $0$**：**不偷**当前第 $i$ 间房；
- **状态 $1$**：**偷**当前第 $i$ 间房。

```
              不偷当前房 (收益 +0)
         ┌───────────────────────────┐
         │                           │
         ▼                           │
   [ 状态 0: 不偷 ] ──────────────► [ 状态 1: 偷 ]
        ▲   │      偷当前房 (收益 +a[i])
        └───┘
   连续不偷 (收益 +0)
```

#### 转移方程

- 如果第 $i$ 间房**不偷**（状态 0）：上一间偷或不偷都完全自由，取两者的最优解：
  $$dp[i][0] = \max(dp[i-1][0], \ dp[i-1][1])$$
- 如果第 $i$ 间房**要偷**（状态 1）：由于相邻限制，上一间**绝对不能偷**，只能从上一间的状态 0 转移而来，并加上当前房屋的现金：
  $$dp[i][1] = dp[i-1][0] + a[i]$$

**核心收获**：打破“一个位置只能存一个状态值”的思维定势，学会用第 2 维划分“合法身份”。

## 第二台阶：单向不可逆阶段机（特权消耗模型）

这是竞赛中最常考、也最具思维魅力的形态：**出题人赋予了你一次全局的“特殊权限”，但这个权限只能在某个连续时间窗口内生效至多一次**。

### 焦点实战：Codeforces 1155D Beautiful Array

> **题目描述**：  
> 给定一个长度为 $n$ 的数组 $a$（$1 \leqslant n \leqslant 3 \times 10^5, -10^9 \leqslant a_i \leqslant 10^9$）以及一个常数 $x$（$-100 \leqslant x \leqslant 100$）。  
> 数组的“美丽度”定义为：**数组中某个连续子数组的最大和（可以为空，空子数组和为 0）**。  
> 你可以挑选 $a$ 中的**至多一个连续子数组**，将其中的所有数值乘以 $x$。求在至多进行一次操作后，数组可能达到的最大美丽度。

---

### 1. 为什么“分步贪心”必然惨败？

很多选手的第一个直觉是：
> *“如果 $x > 0$，我就找全局最大子段乘 $x$；如果 $x < 0$，我就找全局最小子段乘 $x$ 把它变成大正数；最后再跑一遍 Kadane 求最大子段。”*

**这是致命的错误！** 请看下面这个极简反例：

设 $x = -2$，数组为：
$$a = [100, \ \mathbf{-1}, \ 100, \ \mathbf{-100}]$$

- **按贪心逻辑**：
  因为 $x = -2 < 0$，寻找最小连续子段，找到了末尾的 `[-100]`。将它乘以 $-2$ 变成 $+200$。  
  新数组变为 $[100, -1, 100, 200]$，此时的最大子段和是 $200$（或者前三项相加 $199$）。
- **真实最优解**：
  我们应该把中间那个貌不起眼的 **`[-1]`** 乘以 $-2$！  
  数组变为 $[100, \ \mathbf{+2}, \ 100, \ -100]$，此时最大子段是前三项相加：$100 + 2 + 100 = \mathbf{202}$！  
  **$202 > 200$**，贪心彻底失效。

#### 为什么贪心会死？
因为乘以 $x$ 的那段子数组，往往不是孤立存在的，它是**连接左右两段庞大正数子段的“核心桥梁”**！贪心只看到了数值绝对值最大的坑，却忽略了“把一个微小的负数坑填平甚至翻转为正，能让左右两侧巨大的能量汇聚一体”。

---

### 2. 状态机建模：单向三阶段流转

任何一个最终被选出的最优子数组，在从左往右延伸的过程中，关于“乘以 $x$”这件特权，必然完整经历且仅经历以下三个阶段之一或组合：

```
       进入乘 x 区间                    离开乘 x 区间
[ 阶段 0: 尚未乘 x ] ─────────────► [ 阶段 1: 正在乘 x ] ─────────────► [ 阶段 2: 乘 x 已结束 ]
 (当前贡献 a[i])                    (当前贡献 a[i] * x)                   (当前贡献 a[i])
       │                                  │                                     │
       ▼                                  ▼                                     ▼
 保持在阶段 0                       保持在阶段 1                          保持在阶段 2
```

这三个阶段是**严格单向、不可逆的**：
- **阶段 0**：当前元素处于目标子段中，但**特权还没开始使用**（纯原值累加）；
- **阶段 1**：当前元素处于目标子段中，且**当前位置正处于乘 $x$ 的区间内**（乘以 $x$ 累加）；
- **阶段 2**：当前元素处于目标子段中，但**乘 $x$ 的区间已经在前面结束了**（恢复为纯原值累加，且此后绝不允许再乘 $x$）。

---

### 3. 状态定义与转移方程

设以位置 $i$ 结尾的子段状态为：
- $dp[i][0]$：以 $i$ 结尾、**从未使用过乘 $x$** 的最大子段和；
- $dp[i][1]$：以 $i$ 结尾、**位置 $i$ 正在被乘 $x$** 的最大子段和；
- $dp[i][2]$：以 $i$ 结尾、**乘 $x$ 已经结束**的最大子段和。

根据 FSM 状态机图中的所有前驱箭头，我们在每个位置做一次决策：

#### 阶段 0 的转移（普通 Kadane）
当前元素贡献为 $a[i]$。它可以接在前面的阶段 0 后面，或者自己开辟全新子段（对 0 取 $\max$）：
$$dp[i][0] = \max(0, \ dp[i-1][0]) + a[i]$$

#### 阶段 1 的转移（正在乘 $x$）
当前元素贡献为 $a[i] \cdot x$。它可以从哪里来？
1. 从未乘过的阶段 0 刚切换进来（或者从当前位置自己开辟乘 $x$ 子段）；
2. 前面已经在乘 $x$ 了，继续保持阶段 1。

综合取最大值：
$$dp[i][1] = \max(0, \ dp[i-1][0], \ dp[i-1][1]) + a[i] \cdot x$$

#### 阶段 2 的转移（乘 $x$ 已用完）
当前元素贡献恢复为 $a[i]$。它可以从哪里来？
1. 上一个位置刚刚结束乘 $x$，从阶段 1 切换进来；
2. 上一个位置就已经处于阶段 2，继续保持阶段 2。

综合取最大值：
$$dp[i][2] = \max(dp[i-1][1], \ dp[i-1][2]) + a[i]$$

#### 全局答案
因为子数组可以为空（空数组美丽度为 0），也可以在任何位置、任何阶段结束，所以全局答案为所有状态的历史最大值：
$$\text{Ans} = \max\Big(0, \ \max_{i=1}^n \big( dp[i][0], \ dp[i][1], \ dp[i][2] \big)\Big)$$

### 4. 空间压缩与标准实现

由于 $dp[i]$ 只依赖于 $dp[i-1]$，我们甚至不需要开 $O(n)$ 大小的数组，只需维护 3 个变量滚动推进，空间复杂度达到惊人的 $O(1)$！

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    long long x;
    if (!(cin >> n >> x)) return 0;

    vector<long long> a(n);
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
    }

    // 0: 尚未乘 x; 1: 正在乘 x; 2: 乘 x 已结束
    long long dp0 = 0, dp1 = 0, dp2 = 0;
    long long ans = 0;

    for (int i = 0; i < n; ++i) {
        long long v = a[i];
        
        // 注意顺序：更新阶段 2 时需要用到旧的 dp1，因此倒序更新或用临时变量
        long long next_dp2 = max(dp1, dp2) + v;
        long long next_dp1 = max({0LL, dp0, dp1}) + v * x;
        long long next_dp0 = max(0LL, dp0) + v;

        dp0 = next_dp0;
        dp1 = next_dp1;
        dp2 = next_dp2;

        ans = max({ans, dp0, dp1, dp2});
    }

    cout << ans << "\n";
    return 0;
}
```

- **时间复杂度**：$O(n)$，仅需单遍线性扫描，常数极小，轻松通过 $3 \times 10^5$；
- **空间复杂度**：$O(1)$（在线读入甚至无需存储数组）。

## 第三台阶：有向环形状态机（周期动作与冷却期）

除了单向不可逆的模型，现实中还有一类包含**动作流转与冷却重置**的环形状态机。

### 经典模型：买卖股票的最佳时机含冷冻期（LeetCode 309）

> 给定每天的股票价格，你可以尽可能多地完成交易，但必须满足：卖出股票后，你**无法在第二天买入股票（即冷冻期为 1 天）**。

#### 状态设计
每天结束时，账户只可能处于以下三种状态之一：
1. **状态 0（持有股票）**：手头持有一手股票；
2. **状态 1（处于冷冻期）**：今天刚刚卖出股票，明天禁止买入；
3. **状态 2（不持股且非冷冻期）**：处于自由身，明天随时可以买入。

#### 状态流转图

```
                买入股票 (-prices[i])
       ┌─────────────────────────────────────┐
       │                                     ▼
 [ 状态 2: 自由身 ]                    [ 状态 0: 持股 ]
       ▲       ▲                             │
       │       └────────── 保持不买 ─────────┘
  冷冻期自然解除                             │
       │                                     │ 卖出股票 (+prices[i])
       │                                     ▼
       └────────────────────────────── [ 状态 1: 冷冻期 ]
```

#### 转移方程

- **$dp[i][0]$（持股）**：可能今天继续握着不卖，或者今天在自由身（状态 2）刚买入：
  $$dp[i][0] = \max(dp[i-1][0], \ dp[i-1][2] - \text{price}[i])$$
- **$dp[i][1]$（冷冻期）**：只能是今天把手头的股票卖掉了：
  $$dp[i][1] = dp[i-1][0] + \text{price}[i]$$
- **$dp[i][2]$（自由身）**：昨天就已经是自由身，或者昨天的冷冻期今天自然解冻：
  $$dp[i][2] = \max(dp[i-1][2], \ dp[i-1][1])$$

## 总结：如何一眼识破状态机 DP？

在竞赛和面试中，识别状态机 DP 只需要捕捉以下两个核心信号：

1. **题目的主骨架是线性遍历**（顺着时间轴、或者数组下标从 $0$ 走到 $n-1$）；
2. **每个元素身上附带了“身份切换”或“配额约束”**：
   - 选与不选互斥（打家劫舍） $\implies$ **2 状态互斥机**；
   - 某项操作只能执行一次连续区间（CF 1155D） $\implies$ **单向不可逆阶段机（0 $\to$ 1 $\to$ 2）**；
   - 操作后有冷却等待期 $\implies$ **环形流转状态机**。

解题时，**千万不要凭空臆想方程**。最科学的思维习惯是：
> **“第一步先在草稿纸上画出有向图圆圈（每个圈是一个状态）；**  
> **第二步标出所有合法的转移箭头；**  
> **方程自然就是每个圆圈的所有入边取 $\max$ 或 $\min$！”**

只要把有限状态自动机（FSM）这件武器装进你的工具箱，所有这类“带有局部规则限制的线性优化题”，都将迎刃而解！
